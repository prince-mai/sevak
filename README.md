## 🚀 Key Features

- **Mobile-First & Simulator Toggle**: Switch seamlessly between full desktop web portal and simulated iPhone mobile frame.
- **Bilingual Interface**: Dual-language switch for English and हिंदी.
- **Live GPS Tracking**: Interactive Leaflet.js map with route polyline, moving technician marker, and live ETA countdown.
- **Service Booking Engine**: Multi-step booking, address selection across Patna localities, photo/video damage upload, transparent bill breakdown, and UPI/COD payments.
- **Turnkey Project Estimator**: Dynamic area (sq.ft) and material grade calculator with free site engineer survey requests.
- **AMC Configurator**: Society calculator computing annual contracts and per-flat monthly breakdown.
- **Turnkey B2B Tracker**: Visual milestone timeline with architectural blueprint previews.
- **GST Tax Invoice Generator**: Bihar State Code 10, SAC codes, CGST/SGST itemized breakdown, and print/PDF ready.
- **Operations Command Center (`admin.html`)**: Real-time KPI cards, Chart.js telemetry, and live technician dispatch table.

---

## 💻 Tech Stack

- **Frontend**: HTML5, Responsive Tailwind CSS, Lucide Icons, Leaflet.js, Chart.js
- **Backend / Runtime**: Lightweight Node.js server (`server.js`) with built-in REST API endpoints
- **Zero-Dependency Core**: Can also run completely offline by opening `index.html` directly in any browser

---

## 🏁 Quick Start

```bash
# Clone the repository
git clone https://github.com/prince-mai/sevak.git
cd sevak

# Start local server
node server.js
```

Open [http://localhost:3000](http://localhost:3000) for the customer app, or [http://localhost:3000/admin.html](http://localhost:3000/admin.html) for the operations command center.
